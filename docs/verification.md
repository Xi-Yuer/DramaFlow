# 当前验证范围

本轮覆盖用户登录、鉴权与账户中心；其他工作流和模型业务没有实现，不能沿用旧原型的验证结果。

- pnpm check：静态检查、严格类型、加密工具单元测试及所有应用/包构建。
- pnpm test:integration：真实 PostgreSQL 隔离数据库下的认证与健康检查。覆盖匿名访问、关闭注册、来源校验、正确登录、Cookie、资料白名单、角色隔离、会话撤销、停用、密码变更、过期及伪造转发头仍无法绕过的限流。
- 密码变更测试主动传入 revokeOtherSessions=false，验证服务端依然强制撤销其他会话。
- 浏览器：登录、资料保存、安全页、退出登录及桌面/390px 窄屏检查；控制台未发现组件错误。
- 本轮迁移和初始账号开通已在开发环境执行。未清空既有业务数据、Redis 或 RustFS 对象。

真实 HTTPS 代理部署、邮件验证/找回密码、OAuth/MFA，以及完整 Docker 应用镜像重建未在本轮验证；未配置的功能没有展示为可用入口。
