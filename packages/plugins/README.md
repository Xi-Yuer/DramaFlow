# @dramaflow/plugins

保留空入口及模型 SDK 基础依赖，当前没有插件 manifest、安装管理、凭证配置、模型目录或调用适配器。

后续负责受信任的外部能力适配。Capability 表达需要的能力，Plugin 适配外部提供者，Tool 表达可调用操作；三者不构成强制调用层级。用户明确选择插件、模型与凭证，不能隐式替换供应商。浏览器只读取安全声明，适配器和密钥留在服务端。

顶层职责见 [平台核心模型](../../docs/platform-model.md)，具体插件协议留到 [分步设计与实施方案](../../docs/implementation-plan.md) 的第 ⑦ 步确定，不提前恢复旧实现。
