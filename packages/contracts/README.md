# @dramaflow/contracts

共享 JSON 协议和边界校验，不依赖 React Flow、NestJS、Prisma 或 LangGraph。

覆盖身份与项目、Workflow 定义 / 版本 / 运行、节点与边、DataType、RuntimeValue，以及 Artifact / Asset 契约。Manifest 不携带可执行实现。`workflow/metadata` 与 `workflow/workflow-api` 是共享身份和草稿 / 发布协议；`workflow/definition` 是图定义，`workflow/run` 是运行、执行树和人工审核协议。

规则见 [Workflow](../../docs/workflow-model.md)、[Node](../../docs/node-model.md) 和 [数据模型](../../docs/data-model.md)。
